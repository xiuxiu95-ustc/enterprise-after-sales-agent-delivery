# 集成组件与版本边界

本目录把两个能力工程纳入主仓库，使一次 commit 同时定义 Agent 主服务、槽位算法和 RAG 服务版本。

| 组件 | 运行边界 | 主服务适配点 | 已纳入 |
|---|---|---|---|
| `slot_extractor` | Python 包 / 本地模型服务 | `services/slot_extraction.py` | 推理、训练、数据构建、评估、量化、工具循环、版本化数据/实验计划、配置与测试 |
| `modular_rag_mcp` | MCP stdio / in-process | `services/rag.py` | 摄取、混合检索、融合、精排、引用、Trace、Dashboard、评估、配置与测试 |

未纳入 Git 的内容只包括密钥、虚拟环境、下载模型、合并权重、未声明版本化的生成语料、向量数据库、BM25 索引、缓存、日志和临时实验运行目录。这些属于机器相关或可再生产物，不是源码缺失；各组件的配置和说明保留了重建入口。

主服务默认使用仓库内路径。允许环境变量覆盖，是为了部署时把模型或索引挂载到独立数据盘，而不是重新依赖原始源码目录。
